# Axhub 全量云备份与灾难自愈技能 (/备份 & /恢复)

本技能负责为 Axhub 平台及其包含的全部原型工程提供秒级、零垃圾、防冲突的全量云备份与一键自愈恢复。

---

## 🎯 触发场景

1. **用户输入备份指令**：如 `/备份`、`/backup`、*“帮我把现在的工程全量备份到云盘”*；
2. **用户输入恢复指令**：如 `/恢复`、`/restore`、*“帮我从这个备份包恢复：Axhub-FullBackup-xxx.zip”*。

---

## 🛠️ 执行流程

### 一、执行备份 (/备份)
当用户要求备份时：
1. 直接在工作区根目录下执行：
   ```bash
   pnpm backup
   ```
2. 脚本将自动：
   - 扫描当前工作区所有最新原型代码、公共组件、定制后台与技能；
   - 深度排除 `node_modules`、缓存与网盘冲突文件；
   - 自动在包内注入 `RESTORE_GUIDE.md`、`backup-manifest.json` 及 Mac/Win 双击自愈脚本；
   - 自动管理云盘容量：**锁定只保留近期最新的最多 5 份备份**，自动安全清理多余的历史旧备份；
   - 将生成的 ZIP 存入默认的 OneDrive 留痕目录（若受沙盒限制写入失败，则存放于根目录并提示）。
3. 检查脚本输出，向用户展示备份摘要（文件名称、体积大小、当前保留的备份列表及存放位置）。

### 二、执行恢复 (/恢复)
当用户要求恢复时：
1. 若用户提供了 zip 路径：
   ```bash
   node scripts/restore-from-backup.mjs --zip "<备份包路径>"
   ```
2. 若用户未指定路径，直接执行：
   ```bash
   pnpm restore
   ```
   脚本将自动搜索 OneDrive 目录或当前目录下最新的一份备份包进行还原。
3. 脚本会自动完成解压、依赖安装 (`pnpm install`) 与 Vendor 同步。
4. 恢复完成后，告知用户包含的原型列表，并提示可通过 `pnpm dev` 启动服务。
