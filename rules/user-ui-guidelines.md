# 📐 用户专属 UI/UX 设计与排版规范 (User UI Guidelines)

本文档定义 AxHub 页面与表单原型的全局排版、间距、层级与浅色主题规范。**在每次生成或重构原型时必须严格遵守，严禁随意自由布局。**

---

## 1. Grid & Layout (布局与对齐规范)

* **栅格标准**：
  * 统一采用 **12-column grid**（12列栅格系统）。
  * 页面主体内容居中或固定左侧对齐。
  * **形态分层容器限宽**：
    * 表单录入区域最大宽度限制在 **960px - 1100px**（≥1920px / 2560px 宽屏可弹性舒展至 **1180px** 保持视觉舒适居中），禁止无边界全屏拉伸导致输入疲劳；
    * 多列数据台账、表格中心及卡片研判流（如监测预警台账、省厅研判流）解除表单狭窄限制，自适应扩展至 **1720px / 96% 可用宽度**，释放宽屏数据密度，杜绝字段折行。
* **行排布原则**：
  * 严格遵守从左到右的阅读顺序。
  * 整张表单**仅允许两种字段宽度**：
    1. **全宽控件 (col-12)**：长文本、大段输入（如：舆情链接、信息主题、初研意见）。
    2. **双列等分控件 (col-6 + col-6)**：短数据、关联选项（如：涉事属地+通报区县、发生时间+采集单位、预警等级+舆情类型）。
  * ⚠️ **严禁在一行内出现非对称的三列或四列随意分割**（如 col-4 + col-4 + col-4 或 col-3 等）。
* **标签对齐**：
  * 统一采用 **top-aligned label（标签顶部对齐）**。
  * 标签置于控件正上方 **6px** 处，禁止与输入框同排左对齐造成长短不齐的锯齿感。

---

## 2. Spacing & Breathing Room (内边距与留白)

* **控件内边距**：
  * **单行 input / select**：高度固定为 **40px**，水平 padding 统一为 **14px**，文本字号 **15px**。
  * **多行 textarea**：最小高度 **96px**，内部 padding 统一为 **12px 14px**，line-height **1.6**。
* **模块间距**：
  * 字段与字段之间的垂直 gap 固定为 **20px**。
  * 核心操作按钮区（重置 / 提交）上方 margin-top 固定为 **32px**，按钮水平居右或左对齐排列，**严禁居中浮动**。
* **容器边距**：
  * 表单卡片容器统一使用 **32px** 的内留白（padding: 32px），避免内容紧贴边缘。

---

## 3. Typography & Hierarchy (排版与字号层级)

* **字体族**：
  * 优先调用：`system-ui, -apple-system, BlinkMacSystemFont, "PingFang SC", "Segoe UI", sans-serif`。
* **字号梯度（整体字号偏大，强化可读性）**：
  * **页面主标题**：`20px`，`font-weight: 600`，颜色: `#1E293B`。
  * **模块副标题 / 辅助说明**：`14px`，`font-weight: 400`，颜色: `#64748B`。
  * **字段 Label（标签）**：`14px`，`font-weight: 500`，颜色: `#334155`（必填星号标红 `#EF4444`，与文字留空 `4px`）。
  * **输入框正文 / 下拉文本**：`15px`，`font-weight: 400`，颜色: `#0F172A`。
  * **Placeholder（占位符文本）**：`14px`，`font-weight: 400`，颜色: `#94A3B8`。
  * **按钮文字**：`15px`，`font-weight: 500`。

---

## 4. Color Palette & Tone (浅色主题色彩体系)

* **页面背景 (Page Background)**：`#F8FAFC`（极为柔和的浅冷灰）。
* **卡片容器 (Card Container)**：`#FFFFFF`，配 1px 细边框 `#E2E8F0`，圆角 `8px`，轻微弥散投影 `0 1px 3px rgba(0,0,0,0.05)`。
* **主题强调色 (Primary Accent)**：
  * **主色（按钮 / 选中态）**：`#2563EB`（优雅克制的深科技蓝）。
  * **浅色填充（激活区 / 高亮徽标）**：`#EFF6FF`（极其轻淡的浅蓝背景）。
  * **边框色 (Border Default)**：`#CBD5E1`；
  * **悬浮态 (Hover)**：`#94A3B8`；
  * **聚焦态 (Focus)**：`#2563EB`，配合微量光晕（`box-shadow: 0 0 0 2px rgba(37, 99, 235, 0.2)`）。
* **只读与禁用态 (Read-only / Disabled)**：
  * 背景色：`#F1F5F9`；
  * 文本色：`#64748B`；
  * 边框色：`#E2E8F0`；
  * 带有锁形小图标或明确灰色底纹区分。

---

## 5. Visual De-cluttering (视觉降噪规则)

* **杜绝多重胶囊堆叠**：
  * 顶部栏严禁出现连续 3 个以上的彩色 badge。
  * 步骤条统一使用轻量线框 stepper。
  * 非关键状态文字转为纯文本加中点分隔（`·`）。
* **杜绝虚线框装饰**：
  * ⚠️ **除非为文件上传拖拽区，否则一律禁止在常规表单区域（如单选/复选框组合）外层增加彩色或虚线边框包裹。**
* **结构清晰优先**：
  * 整个表单页面层级严格扁平化，仅允许三层结构：
    `页面导航 -> 主内容白色卡片 -> 纯净表单流`。

---

## 6. Scenario Navigation Bar (顶部场景中控导航栏双极化布局规范)

* **左右双极化规整区块架构 (Bipolar Grouping)**：
  * 严禁顶栏内部各功能组件在宽屏下被 `space-between` 或大留白随意拉伸分散，避免视觉重心涣散、无法集中的情况。
  * 顶部场景引导导航栏统一划分为 **「左侧核心业务流区块」** 与 **「右侧研发操作区块」**，两极化排布：
* **左侧核心业务流区块 (从左到右紧凑居左排列)**：
  * **组件组成**：`【场景名称/微标】 ➔ 【用户场景 (悬停浮窗)】 ➔ 【相关流程步骤 (1➔2➔3)】`；
  * **布局约束**：三者统一包裹在左侧弹性容器内，依次紧密排列，组件间水平 gap 控制在 **10px - 14px**，**中间严禁出现过多留白或非必要弹性拉伸**；
  * **视觉目标**：使用户视线聚焦于清晰连续的业务上下文（“我是谁、做什么、处于流程第几步”）。
* **右侧研发与系统操作区块 (紧凑居右排列)**：
  * **组件组成**：`【需求规格与批注按钮】 + 【隐藏/纯净演示按钮 (快捷键 V)】`；
  * **布局约束**：统一靠右对齐，工具按钮间距 **8px**；
  * **视觉目标**：将所有开发验收、批注调阅与演示控制集中在右侧，与左侧纯业务流形成明确的视觉区隔，方便快速调用而不干扰业务演示。

---

## 7. Dev Drawer & Workspace Inspection (全量需求规格抽屉与主工作区自适应并排规范)

* **主功能区居中与并排无遮挡原则 (Side-by-side Docking)**：
  * 调出「全量需求规格与细节说明」抽屉（宽度约占屏幕 28%~32%，`clamp(420px, 28vw, 680px)`）时，主工作区域应自适应平滑缩进剩余可用宽度 (`calc(100% - drawerWidth)`)，杜绝大面积遮挡主要内容；
  * 核心功能（如表单卡片、台账表格）在剩余可视工作区中始终保持水平居中，两侧留有对称留白；
  * 严禁使用深色/磨砂模糊遮罩阻断用户视线与操作，确保查验规格时界面全量要素均清晰可见且可操作；
* **批注与组件联动高亮定位**：
  * 点击抽屉内的业务规则/批注卡片时，主功能区对应的界面组件必须平滑滚动至可视区域中央（`scrollIntoView({ behavior: 'smooth', block: 'center', inline: 'nearest' })`），并触发呼吸脉冲光晕与高对比度外框（`spec-linked-glow`），确保任何双列等分右侧字段（如通报地市、采集单位等）绝对处于无遮挡的可视窗口内；
  * 点击主界面原位批注角标（①②④）时，抽屉平滑展开并自动定位至对应规则卡片，实现双向精准联动。
