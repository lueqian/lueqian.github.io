# Eagle DataStory

## 业务与功能

### 核心目标

`eagle_datastory` 是“数说蓝鹰”定向采集与额度审计原型，围绕搜索、全网专题、重点源、采集任务和额度明细形成“发现内容 -> 创建采集任务 -> 查看执行结果 -> 审计额度消耗”的闭环。

### 功能清单

- **搜索**：支持全网检索、条件筛选、结果列表展示，并可从搜索结果创建采集任务。
- **全网专题**：展示专题文章、平台筛选、情感筛选、专题树，并可基于专题创建采集任务。
- **重点源**：展示重点账号列表、账号详情与帖子列表，并可基于重点源或帖子创建采集任务。
- **采集任务**：展示采集任务列表（支持“未开始/进行中/已结束”三态）、筛选、启动与结束状态控制、修改、删除、详情和新建任务抽屉。
- **额度明细**：按任务维度展示额度消耗汇总，并在抽屉中展示任务执行明细。

### 交互要点

- 点击左侧导航切换一级页面，顶部标题同步当前页面名称。
- 重点源页面显示顶部二级导航，默认选中“重点源管理”。
- 点击“新建任务”打开右侧抽屉，抽屉标题显示“新建采集任务”。
- 点击采集任务列表中的“修改”打开右侧抽屉，抽屉标题显示“修改采集任务”，并预填当前任务数据。
- 在新建与修改采集任务的配置中，支持通过 CSV 文件批量导入链接，下载的 CSV 文件模板仅保留首列 “链接地址”，系统解析导入时也仅保留链接地址数据。
- 任务详情下方展示采集详情，列表展示每次采集任务执行批次（采集批次、执行时间、本次有效链接数、本次消耗额度、采集状态），点击单次采集批次的“详情”打开抽屉：对于评论采集，按“一条评论一行”的效果平铺展示其链接、标题、信源、作者、评论内容、评论时间（如有）等信息；对于互动量更新，按链接行展示当次采集下的互动量快照数据。
- 已启用且已有采集数据的任务禁止修改，鼠标悬停展示禁用原因。
- 点击操作列的“启动”、“结束”或“重启”按钮，即时变更任务对应的状态标签，并相应更新模拟采集数据。

### 数据来源

- **需求来源**：[prd.md](/Users/lueqian/Axhub/src/prototypes/eagle_datastory/prd.md)
- **数据类型**：采集任务、搜索结果、专题文章、重点源账号、帖子、额度消耗流水。
- **数据源**：当前原型使用页面内 mock 数据。
- **关键字段**：
  - `task_name`：采集任务名称。
  - `task_type`：采集类型，包含互动量更新和评论区采集。
  - `scope_type`：采集范围，包含专题、重点源和链接。
  - `platforms`：采集平台集合。
  - `status`：任务开启或关闭状态。
  - `link`：链接任务的目标链接。
  - `last_collected_at`：单条链接最新一次采集时间。
  - `interaction_last`：单条链接最新一次互动量。
  - `comment_last`：单条链接最新一次有效评论数量。

## 布局与结构

### 整体布局

- **布局模式**：固定左侧导航 + 顶部栏 + 主内容区。
- **导航宽度**：展开 220px，折叠 64px。
- **顶部栏高度**：56px。
- **内容区**：流式宽度，页面内部按表单、列表、详情区域组织。
- **采集任务抽屉**：右侧滑入，宽度 640px，用于承载新建和修改任务表单。
- **采集任务详情页**：最大宽度 1120px，上方为任务概况 Descriptions（已简化，去除累计总量、最近一次增量），下方为采集详情卡片。
- **采集明细抽屉**：右侧滑入，宽度 850px，用于展示单次采集批次内所抓取的所有链接及数据快照列表。

### 响应式适配

- **桌面端（≥1200px）**：保持左侧导航、顶部栏和内容区的工作台布局。
- **平板端（768-1199px）**：内容区横向滚动或收缩表格列，抽屉保持右侧滑出。
- **移动端（<768px）**：当前原型以桌面管理后台为主，不作为主要适配目标。

## 视觉规范

### 设计规范来源

**设计规范来源**：主题 `/Users/lueqian/Axhub/src/themes/antd-new`

### 自定义设计要点

- 全局框架使用深色导航和顶部栏，内容区使用浅色表单和表格，符合后台工作台场景。
- 主色使用科技蓝，强调导航选中态、主按钮和关键链接。
- 页面样式按历史页面前缀组织，包括 `sp-`、`sr-`、`nt-`、`ks-`、`ct-`、`qf-` 等，后续优化应优先局部修改对应页面前缀。

### 组件状态

- **默认态**：表单、表格和列表保持高信息密度，文本清晰可读。
- **悬停态**：列表行、操作链接、导航项提供视觉反馈。
- **禁用态**：不可修改任务使用弱化文字，并通过 Tooltip 说明原因。
- **加载态**：任务表单提交和额度预估提供 Loading 反馈。
- **抽屉标题态**：新建入口显示“新建采集任务”，修改入口显示“修改采集任务”。
- **链接详情态**：链接列表行提供“详情”操作，抽屉标题根据采集类型显示“互动量变动统计”或“评论内容明细”。
