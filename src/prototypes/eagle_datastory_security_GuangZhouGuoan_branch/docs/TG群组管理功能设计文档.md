## 需求背景

针对广州国安部门的业务需求，在数说蓝鹰舆情监测系统的"重点源"模块中新增"TG群组管理"功能。该功能主要用于对Telegram平台上的特定群组进行定向监测，帮助相关部门及时发现和处置互联网安全相关的敏感舆情。

---

## 视觉风格

- **整体风格**：科技商务感
- **背景色**：浅灰 `#F5F7FA`
- **侧边栏**：深蓝 `#1A2138`
- **主色调**：蓝色 `#3b82f6`
- **成功/增长色**：绿色 `#10b981`
- **文字主色**：`#1f2937`
- **文字次色**：`#6b7280`
- **卡片背景**：白色 `#ffffff`，圆角 10px，微阴影

## 页面结构

### 1. TG群组管理主页

#### 1.1 顶部Tab导航

位于页面顶部二级菜单，包含以下Tab：
- 重点源监测
- 重点源管理
- 信源搜索
- 预警管理
- **TG群组管理**（当前高亮状态）

#### 1.2 总览卡片 (Stats Cards)

横向排列三个统计卡片：

| 卡片 | 指标 | 数值 | 趋势 | 图标 |
|------|------|------|------|------|
| 卡片1 | 已接入群组 | **126** | +12.6% 较昨日 | AppstoreOutlined（淡蓝底色） |
| 卡片2 | 总成员规模 | **52.8K** | +8.4% 较昨日 | TeamOutlined（淡蓝底色） |
| 卡片3 | 今日发文总量 | **1,284** | +19.2% 较昨日 | FileTextOutlined（淡蓝底色） |

卡片设计规范：
- 白色背景，1px浅边框，圆角10px
- 左侧：指标名称（13px灰色）+ 数值（28px加粗深色）
- 右上：淡蓝圆形图标容器（44px）
- 右下：绿色趋势箭头 + 百分比 + "较昨日"

#### 1.3 列表区

**筛选栏**：
- 左侧：Tab切换（全部群组、高活跃、待评估、内容型、交易型、品牌型）
  - 激活态：蓝色背景填充，白色文字，圆角胶囊
  - 默认态：透明背景，灰色文字
- 右侧：搜索框（占位符"搜索群名称、管理员或群ID"）

**表格字段**：

| 列名 | 宽度 | 内容说明 |
|------|------|----------|
| 群组信息 | 自适应(flex:1) | 圆角头像(40px) + 群组名称(14px加粗) + 简介(12px灰色) |
| 管理员 | 120px | 用户名 |
| 成员数 | 90px | 数字，千分位格式 |
| 群ID | 180px | 蓝色等宽字体，带#前缀，hover显示复制图标 |
| 今日发文 | 90px | 数字 + "篇" |
| 标签 | 200px | 多个胶囊标签，蓝色文字+淡蓝背景+蓝色边框 |
| 操作 | 80px | "查看详情"蓝色链接 |

### 2. 成员活跃详情（右侧抽屉 Drawer）

#### 触发方式
点击列表任一行的"查看详情"按钮，从右侧滑出抽屉。

#### 抽屉宽度
380px

#### 内容结构

| 区域 | 内容 |
|------|------|
| 头部 | 标题"群成员信息" + 关闭按钮；群组名称（15px加粗）；管理员 + 群ID（12px灰色） |
| 搜索框 | 占位符"筛选群成员名称" |
| 成员列表标题 | "成员信息" |
| 成员列表 | 垂直排列，每行：圆形头像(36px) + 成员名称(13px) + 成员ID(u101...) + 右侧"XX次互动" |
| 底部 | "查看详情 →"链接 |

## 数据字段定义

### TG群组数据结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | number | 内部唯一标识 |
| groupId | string | Telegram群组ID（如 -1002194108821） |
| groupName | string | 群组名称 |
| description | string | 群组简介 |
| avatar | string | 头像文字（用于生成渐变色头像） |
| admin | string | 管理员名称 |
| memberCount | number | 成员数量 |
| todayPosts | number | 今日发文数 |
| tags | string[] | 标签列表 |

### 群成员数据结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | number | 内部唯一标识 |
| name | string | 成员名称 |
| memberId | string | 成员ID（如 u101） |
| avatar | string | 头像文字 |
| interactions | number | 互动次数 |

## 交互说明

| 交互 | 触发 | 效果 |
|------|------|------|
| 筛选Tab切换 | 点击Tab | 切换群组筛选条件，激活态高亮 |
| 搜索 | 输入关键词 | 实时过滤群组列表 |

| 复制群ID | hover群ID | 显示复制图标，点击复制 |

## 技术实现说明

### 文件结构

**新增/修改文件**：
- `pages/TGGroupManage.tsx` - TG群组管理页面组件（V2.0 重写）
- `style.css` - 追加 `tg2-` 前缀样式
- `index.tsx` - 二级菜单配置（V1.0已添加）
- `pages/Sources.tsx` - activeSubNav路由支持（V1.0已添加）

### 组件架构

```
Sources (pages/Sources.tsx)
└── activeSubNav = 'tg_group' → TGGroupManage
    ├── StatsCards（总览卡片 x3）
    ├── FilterBar（筛选Tab + 搜索框）
    ├── Table（群组列表表格）
    │   └── Row → "查看详情" → Drawer
    └── Drawer（右侧抽屉）
        ├── Header（群组名称 + 管理员 + 群ID）
        ├── Search（成员搜索框）
        ├── MemberList（成员列表）
        └── Footer（查看详情链接）
```

### 样式规范

所有TG群组管理V2样式使用 `tg2-` 前缀，与V1的 `tg-` 前缀隔离：

| 样式类名 | 说明 |
|----------|------|
| `.tg2-page` | 页面容器 |
| `.tg2-stats-row` | 统计卡片行 |
| `.tg2-stat-card` | 统计卡片 |
| `.tg2-filter-bar` | 筛选栏 |
| `.tg2-filter-tab` | 筛选Tab胶囊 |
| `.tg2-table-wrapper` | 表格容器 |
| `.tg2-table-row` | 表格行 |
| `.tg2-tag-pill` | 标签胶囊 |
| `.tg2-drawer` | 右侧抽屉 |
| `.tg2-member-item` | 成员列表项 |
