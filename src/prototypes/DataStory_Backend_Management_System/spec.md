# DataStory Backend Management System 原型规格说明

## 项目定位

本原型为“后台运营管理系统”，用于管理数说蓝鹰相关客户、权限、组织、数据配置与运营后台模块。当前实现重点覆盖系统后台基础框架、Dashboard 总览、蓝鹰客户列表、客户配置页及部分建设中模块占位。

## 信息架构

### 全局框架

- 左侧固定侧边栏，默认宽度 240px，支持折叠为 80px。
- 顶部固定导航栏，高度 64px。
- 主内容区使用浅灰背景，页面内容以白色卡片承载。
- 页面导航使用内部状态模拟路由，并通过顶部面包屑展示当前层级。
- 从客户列表进入客户配置时，面包屑追加二级页面；点击“返回”回到客户列表。

### 侧边栏菜单

当前侧边栏包含以下一级菜单：

- 产品管理
- 权限设置
- 角色权限管理
- 蓝鹰客户管理
  - 客户列表
  - 外部用户
  - 行业设置
  - 预警平台配置
  - 外部微信管理
- 智能外呼客户管理
- 大禹客户管理
- 内部用户管理
- 文旅后台管理
- 客户列表
- 组织机构管理
- 风险模型
- 媒体清单
- 操作日志
- 预警中心

其中“蓝鹰客户管理”默认展开。除 Dashboard、客户列表、客户配置外，其余菜单目前以占位页形式展示。

## 页面规格

### 1. Dashboard

Dashboard 是系统默认入口页面。

核心内容：

- 顶部 4 个统计卡片：
  - 今日采集数据量：12,846
  - 正面舆情：3,521
  - 预警事件：847
  - 活跃客户数：156
- 舆情趋势分析：
  - 展示最近 7 天趋势柱状图。
  - 分为正面、负面、中性三类图例。
- 媒体来源分布：
  - 新闻网站、社交媒体、论坛博客、视频平台、其他。
  - 使用横向进度条展示占比。
- 最新预警：
  - 展示预警等级、标题、时间。
  - 包含“查看全部”入口样式。
- 热点关键词：
  - 以标签形式展示关键词，部分热点词使用强调样式。

路径入口：侧边栏“蓝鹰客户管理 / 客户列表”。

页面结构：

- 顶部筛选区：
  - 所属组织机构选择
  - 上级客户选择
  - 客户名称输入框
  - 客户状态选择
- 数据表格：
  - 表格支持横向滚动。
  - 左侧序号列固定。
  - 右侧操作列固定。
  - 支持斑马纹、悬浮高亮。
- 表格字段：
  - 序号
  - 客户ID
  - 系统显示名
  - 所属行业
  - 下调用户数
  - 客户角色
  - 销售
  - 售前
  - 申请人
  - 发送邮箱
  - 注册时间
  - 到期时间
  - 账号状态
  - 操作
- 已实现交互：
  - 点击客户 ID 复制完整 ID，并显示“已复制客户ID”Toast。
  - 鼠标悬停客户 ID 时展示完整 ID 浮层。
  - 点击账号状态开关可切换启用/停用状态。
  - 点击“配置”进入客户配置页，并将客户名称传入二级页面标题。
  - 分页支持上一页、下一页和页码切换，当前总数为 1145 条。
- 操作按钮：
  - 发送
  - 编辑
  - 配置
  - 查看

### 3. 客户配置

入口：客户列表行操作“配置”。

页面结构：

- 顶部展示客户名称。
- 右侧提供“返回”按钮。
- 页面内包含一级 Tab：
  - 服务项配置
  - 推荐配置
  - 费用统计
  - 跟踪配置
  - AI配置
- 当前已实现内容：
  - 服务项配置
  - 费用统计
- 底部固定操作栏：
  - 保存按钮

#### 3.1 服务项配置

服务项配置包含“专题数据配置”和“任务数据配置”两个一级配置组。

专题数据配置（包含二级配置组“专题配置”）：

- 历史数据查询量：
  - 不限制
  - 按数量
  - 按数量时显示步进器，默认 5,000,000
- 查询最早时间：
  - 不限制
  - 按指定时间
- 专题配置时间：
  - 默认：历史 7 天，未来 30 天
  - 最长：历史 90 天，未来 30 天
- 默认查询时间：
  - 当天
  - 24小时
  - 3天
  - 7天
- 可选时间长度：
  - 步进器，默认 90 天
- 关键词组合限制：
  - 必填项
  - 步进器，默认 3000
- 关键词字数上限：
  - 必填项
  - 步进器，默认 2000
- 指定作者上限：
  - 最多 10 个
  - 长度 50 字
- 指定域名上限：
  - 最多 10 个
  - 长度 50 字

任务数据配置（包含二级配置组“搜索配置”）：

- 搜索查询时间：
  - 默认 7 天
  - 最长 90 天
- 额度预警配置（从费用统计中转移至此）：
  - 提供一个输入框配置预警比例 N，当额度低于总额度的 N% 时进行提醒
  - 输入限制在 0～100 整数
  - 默认值为 30%

#### 3.2 费用统计

费用统计包含二级 Tab：

- 数据包额度（条）
- 采集任务额度（次）

状态栏与配置开关：

- **数据包额度（条）**：顶部展示“统计数据”状态栏。开启时展示启用时间、有效期与剩余天数。
- **采集任务额度（次）**：顶部替换为两个独立的开关配置：
  - **采集任务**：开启/关闭。备注：开启后，客户系统中支持使用采集任务功能。若关闭该开关，下方所有配置与数据列表折叠隐藏，且“额度明细”开关同步禁用变灰。
  - **额度明细**：开启/关闭。备注：开启后，客户系统中允许查看采集任务消耗的具体额度。若关闭该开关，下方“任务额度明细”模块样式微弱置灰，且展示提示“（已关闭：客户系统中不可查看此明细）”，但后台管理员仍可继续查询、导出。

采集任务额度（次）：

展示顺序为：额度包管理、信源计费规则（原名：采集平台管理）、任务额度明细（原名：采集任务额度使用明细）。

- 额度包管理（原名：额度包列表）：
  - 展示有效期、操作记录、数据量、使用量、状态、操作
  - 状态包括：“使用中”（当总量大于已使用额度时）和“已用完”（当额度已全部消耗时），取消“已停用”的歧义状态
  - 支持新增额度包
  - 支持编辑额度包（合并减量和延期操作至统一的编辑弹窗，且在保存时会根据数据量和使用量动态计算并更新状态）
  - 支持删除额度包，并弹出删除确认弹窗
- 信源计费规则（原名：采集平台管理）：
  - 默认在列表渲染所有计费卡片（小红书、抖音、微博、今日头条、B站、知乎）
  - 卡片左侧前置配置一个“复选框”，勾选后才允许用户配置该平台的“互动量更新单次费用”和“评论区采集单次费用”；未勾选状态下卡片变灰，且输入框处于 disabled 状态
  - 模块头部右侧提供“全选所有平台”复选框，支持一键全选或取消全选所有平台
  - 费用输入范围为 0 到 100 元，保留两位小数
- 任务额度明细（原名：采集任务额度使用明细）：
  - 支持多维度筛选：任务名称模糊查询、创建时间范围、采集范围（全网专题/重点源/链接）、采集来源平台、采集类型。
  - 任务消耗汇总表展示：任务名称、创建时间、采集范围、采集来源平台标签组、采集类型、已消耗额度（突出红色）、任务当前状态、以及“查看明细”操作。
  - 查看明细抽屉：点击任一任务可从右侧滑出抽屉，显示该任务在各个时间点、平台的采集成功率、单次费用与额度扣除，对于失败采集可悬停显示风控失败状态码/原因。
  - 导出明细：支持选择“全部”或“已筛选结果”，并选择导出时间范围，模拟 3 秒后台合并导出并下载 `.xlsx` 表格。

### 组件风格

- 整体采用 Ant Design 后台系统风格。
- 表格、筛选区、配置表单、弹窗均为白底轻阴影卡片。
- 表格支持固定列、横向滚动、斑马纹与悬浮高亮。
- 表单使用左侧标签、右侧控件的配置后台布局。
- 开关、Radio、Checkbox、Stepper 均为自定义样式实现。
- 弹窗采用居中遮罩层，支持关闭、取消、确认/删除操作。

## 交互规则

- 点击侧边栏叶子菜单后，重置面包屑并进入对应页面。
- 点击带子菜单的一级菜单时，仅展开或收起子菜单。
- 顶部折叠按钮控制侧边栏宽度。
- 顶部全屏按钮调用浏览器全屏能力。
- 顶部用户区域点击后展示下拉菜单，再次点击或点击外部关闭。
- 客户配置页点击返回时，回退到上一层面包屑。
- 当前原型以本地模拟数据和前端状态为主，不接入后端接口。
