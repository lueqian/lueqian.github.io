# 蓝鹰一体化智控平台规格说明 (spec.md)

## 1. 系统定位与设计原则
本原型 1:1 像素级复刻公安网安真实生产系统界面（包含监测预警、应急处置、手工上报、AI辅助研判等核心场景），全量采用地道公安政务用语，严禁出现非业务原生的解说性卡片与文字折行，采用“左侧可收缩导航（Sider） + 顶部通栏（Header） + 5 列标准栅格（Grid）”的中台布局体系。

---

## 2. 界面骨架与布局架构 (Layout Architecture)

### 2.1 左侧侧边栏 (AppSider)
- **展开状态（宽 220px）**：
  - 顶部 Logo 区：蓝色云朵图标 + 粗体蓝字 `舆情一体化智控平台`。
  - 菜单项：`源头防控`（盾牌图标）、`监测预警`（雷达图标，激活态浅蓝底+高亮蓝条）、`应急处置`（表单/公文包图标）、`态势感知`（折线图图标）。
  - 底部操作栏：包含折叠按钮与文字 `收起侧边栏`。
- **收起状态（宽 64px）**：
  - 顶部仅保留居中蓝色云朵图标；
  - 菜单以图标居中呈现，鼠标悬浮带 Tooltip 提示；
  - 底部操作栏按钮变为展开图标，支持平滑展开与收缩。

### 2.2 顶部通栏 Header (高度 52px，白色底)
- **左侧**：当前模块面包屑路径，如 `监测预警 > 舆情列表`、`应急处置 > 任务列表`。
- **中右侧**：胶囊搜索框（`全网 ∨` + `请输入关键词搜索`）。
- **右侧**：
  - `欢迎 王浩！` | `修改密码` | `值班表`；
  - 角色模拟切换下拉框：`岗位: [市局网安支队-审核岗 ∨]`（下拉选项驱动全局业务状态）；
  - 换肤衣服图标、带红点警铃图标、退出登录图标。

## 3. 搜索过滤面板标准化对齐规范 (5 列 Grid 系统)

为彻底杜绝表单 Label（如“编号”、“排序”）纵向折行以及控件宽窄不一问题，全站搜索面板统一采用 **5 列固定栅格系统（CSS Grid）**：

- **Label 规范 (`.search-label`)**：
  - 固定宽度 `72px`，右对齐；
  - 强制应用 `whitespace-nowrap flex-shrink-0 text-right`，绝对禁止换行；
  - 字号 `13px`，行高 `32px`。
- **控件规范**：
  - 右侧输入框/下拉框/日期选择器统一 `flex-1` 撑满所在单元格；
  - 统一高度 `32px`，圆角 `4px`。

### 3.1 监测预警模块落位
- **第 1 行（5 列严格对齐）**：`内容搜索`、`上报区县`、`发布时间`、`信息状态`、`舆情等级`。
- **第 2 行（5 列严格对齐）**：`舆情类型`、`专项任务`、`责任属地`、`上报时间`、`信源渠道`。
- **第 3 行（底栏功能对齐）**：
  - 第 1 列：`排序方式`；
  - 第 2 列：`编号检索`（整词横排，宽度在 72px 内，绝不换行）；
  - 第 3~4 列：视图切换单选按钮组 `[详细视图] [研判视图] [简要视图]`；
  - 第 5 列：右对齐放置 `[重置]`、`[查询]`、`[收起 ^]`。

### 3.2 应急处置模块落位
- **第 1 行（5 列严格对齐）**：`信息搜索`、`下发时间`、`处置时间`、`已发指令`、`指令状态`。
- **第 2 行（5 列严格对齐）**：`日期区间`、`刊号检索`、`未发指令`、`相关人员`、`任务编号`（整词横排，绝不换行）。
- **第 3 行**：右侧严格对齐 `[重置]`、`[查询]`、`[收起 ^]`。

## 4. 业务流转与多角色权限体系

### 4.1 四类实战岗位与切换矩阵
顶栏身份切换器提供 4 类专属实战岗位：
1. `市局网安支队 - 审核岗 (互联网独立版)`（默认）：汇聚地市各区县上报舆情，行使市局审核定稿与【同步省厅】把关权。
2. `省厅网安总队 - 指挥岗 (公安内网版)`：汇聚全省统采与地市提报的研判流。
3. `姑苏分局网安大队 - 经办岗 (互联网独立版)`：下属基层经办端，严禁直报省厅，仅能提交地市库。
4. `沭阳县局网安大队 - 经办岗 (公安内网未采购版)`：内网基层端，展示精准归属本区县的非高敏第三方及本地数据。

### 4.2 监测预警页——市局账号把关并同步省厅流程
1. **列表与筛选区**：
   - 左侧保持展开 220px / 收折 64px 的标准侧边栏；
   - 顶栏岗位显示为 `市局网安支队 - 审核岗 (互联网独立版)`；
   - 搜索面板严格遵循 5 列等高对齐，Label 固定 72px 严禁折行；
   - 业务 Tab 定位至 `区县上报`（带待办数量徽标）。
2. **列表卡片与状态**：
   - 默认展示由下属区县（如 `姑苏分局 - [张警官]`）上报的涉稳舆情；
   - 待把关时，卡片底部状态 Tag 呈现为橙黄底色 `[待市局把关]`；
   - 操作按钮栏保留：`一键搜索`、`复制信息`、`未处置`、`信息详情`、`AI辅助研判`。
3. **AI辅助研判弹窗交互**：
   - 点击卡片右侧【AI辅助研判】唤起大尺寸双栏模态弹窗；
   - 左侧：三大指数卡片（舆情指数、网信指数、部级指数）与事件概述；
   - 右侧【分析研判】栏：市局用户可就地编辑修改 `人工研判意见`，并重新调整 `等级`（一级特急~四级低）；
   - 弹窗底部操作栏：右侧展示白底辅助按钮 **【仅保留地市自办】** 与醒目蓝色主按钮 **【审核通过并同步省厅】**；
   - **点击【审核通过并同步省厅】**：触发全局 Toast：`“审核通过，数据已留存快照并成功同步至省厅内网数据库”`，弹窗关闭，卡片底部状态 Tag 立即动态更新为绿色的 `[已同步省厅·市局终审版]`。
   - **点击【仅保留地市自办】**：触发全局 Toast：`“已转为地市自办，数据保留于地市库，不同步省厅”`，状态 Tag 更新为 `[仅保留地市自办]`。

### 4.3 监测预警页——省厅账号研判并下达指令到市局流程
1. **环境与数据源展示**：
   - 当前登录角色切换驱动为：`省厅网安总队 - 指挥岗 (公安内网版)`；
   - 顶栏环境显示带指示绿点的 `公安内网端` 标识，岗位显示为 `省厅网安总队 - 指挥岗 (公安内网版)`；
   - 导航选中 `监测预警`，Tab 栏切换为省厅专属口径，停留在 `地市上报`（带徽标）或 `全部`；
   - 列表中展示由市局审核同步上来的舆情数据（如 `关于涉某重点企事业单位的网络谣言线索`）：
     - 数据来源 Tag 规范展示为：`[苏州市公安局上报]`；
     - 卡片右侧展示舆情指数（`42.5`）与黄色五星评级。
2. **省厅直派处置指令交互流程**：
   - 点击该卡片右侧的 **【AI辅助研判】** 按钮进入处置弹窗；
   - 弹窗右侧上方展示蓝色边框操作按钮 **【下达处置指令】**（点击可自由展开/折叠配置面板）；
   - **指令下发配置项**：
     - `执行目标单位`：下拉选择器（默认自动选中来源单位：`苏州市公安局`）；
     - `处置要求`：复选框支持勾选 `线下核实`、`属地删帖`、`落地查人`、`情况反馈`；
     - `处置时限`：选择 `24小时内`；
     - `补充批示意见`：TextArea 预填政务风格指导批示：`请苏州市局迅速安排核查当事人具体动向，防止二次煽动炒作，处置进展及时回传。`；
   - **提交交互**：
     - 点击底部醒目蓝色主按钮 **【确认下达指令】**；
     - 触发 Ant Design Notification 通知提示框：`“指令下达成功，任务单号 ZL20260911001 已流转至苏州市公安局内网待办”`；
     - 弹窗关闭，卡片状态 Tag 立即动态变更为高亮蓝紫色的 `已下发指令 (苏州市公安局处置中)`。

### 4.4 应急处置页——市局账号转派省厅指令至下属区县流程
1. **列表展示与任务感知**：
   - 侧边栏定位至 `应急处置` 模块，顶栏岗位为 `市局网安支队 - 审核岗 (内网协同视角)`；

     - 任务摘要完整呈现省厅批示要求与 24 小时限时督办意见；
     - 卡片顶栏醒目标注：`[省厅督办指令]`、`[待处置]`；
     - 卡片右侧保留紫色大号 `舆情指数 42.5` 色块。
2. **核心交互流程（市局二次转派至具体区县）**：
   - 卡片右下角操作组展示主操作按钮 **【二次指派区县】**（带分享流转图标）；

     - `指令动作`：自动继承省厅选中的 `线下核实`、`属地删帖`，并支持市局追加勾选 `重点人管控`、`情况回传`；

     - 弹窗关闭，任务状态由 `待处理` 动态流转至 `已转派`，卡片打上浅蓝底标签：`[已转派：姑苏分局办理中]`；
     - 右侧操作按钮更新为 `查看进展`（点击可穿透追踪民警警号、签收状态与实地走访实时日志）。

## 5. “部门管理”与“工具箱其他业务”1:1 像素级复刻规范

### 5.1 全局顶栏与导航布局规范 (Header & Navigation Layout)
1. **左上角唯一系统标识**：
   - 统一保留在左侧导航侧边栏（AppSider）顶部（高度 `56px`），展示蓝色云朵图标 + 粗体蓝字 `舆情一体化智控平台`，严禁在全局顶栏重复出现双重系统标识。
2. **全局顶栏 Header (56px 高度，纯白底色，下边框浅灰 `#F0F0F0`)**：
   - **左侧**：模块面包屑路径（如 `部门管理 > 忠县 - 用户列表`、`监测预警 > 舆情列表`）与网络环境标签（`公安内网端` / `互联网端`）；彻底移除左上角横排菜单切换入口，避免导航职责混乱。
   - **中右侧**：胶囊圆角搜索框（左侧下拉 `全网 ∨`，中间细竖线分隔，占位符 `请输入关键词搜索`，右侧放大镜检索按钮）。
   - **右侧**：
     - 用户文本：`欢迎 杨吉！` + 蓝色小剪贴板图标（支持一键点击复制姓名）；
     - 快捷链接：`修改密码` | `值班表`；
     - 角色下拉框：`岗位: 材料汇编岗 ∨`（支持切换工作岗位）；

3. **左侧侧边栏导航 (AppSider)**：
   - 侧边栏菜单由上至下依次为：`源头防控`、`监测预警`、`应急处置`、`部门管理`、`态势感知`（已彻底移除工具箱入口及对应浮层，保持纯粹政务业务流）。


### 5.2 左侧部门树面板 (Left Sider - 部门列表)
1. **面板规格**：固定宽度 `280px`，白底，右侧浅灰边框 `#E8E8E8`。
2. **顶部操作栏**：
   - 左侧：粗体文本 `部门列表` + 排序图标（上下箭头 `⇅`）；
   - 右侧：浅蓝链接文字 `添加部门`（点击唤起 480px 居中弹窗）；
   - 搜索框：Input 组件，占位符 `搜索部门`，带前置放大镜图标；
   - 顶部通栏按钮：蓝底白字扁平按钮 `全部用户`（点击展示全单位总用户列表）。
3. **部门树结构 (Tree 规范还原)**：
   - **层级区分微标 [市局] / [区县]**：
     - 根节点与市直属节点（如 `网安`、`总公司`、`区县分公司`）：节点名称前带有蓝底白字微型标签 **`[市局]`**（`#1677FF` 蓝底白字，10px 方块标签）；

   - **层级架构**：

1. **“编辑部门 / 添加部门”弹窗 (480px 居中 Modal)**：

     - `涉事属地:` Select 下拉选择器，占位符 `请选择`，下方附注：`ⓘ 选择后主动发现该属地数据会自动分发至该部门`；
     - **`下级单位:`** Switch 单一开关，开启后证明该部门属于下级单位（区县节点，打 `[区县]` 绿标与 `[下级单位]` 徽标）；未开启证明为上级部门（市局节点，打 `[市局]` 蓝标与 `[上级部门]` 徽标）。下方附灰字说明：`开启后，证明该部门属于下级单位，未开启为上级部门`；
     - **`上报需审核:`** Switch 开关，控制该部门上报是否需要上级审核把关，下方附灰字说明：`开启控制上报需审核，并指定审核的目标部门`；
     - **`* 审核目标部门:`** Select 下拉选择器（与“上报需审核”开关关联，**仅在“上报需审核”开关开启时联动显示**），提供可选上级部门（如 `网安支队`、`总公司`），默认选中排序靠前的一个上级部门（`网安支队`）；
