# Specification: Gov Control Platform (智控平台)

## 📌 项目背景
本项目是“数说蓝鹰”舆情系统针对政府端的定制化版本，侧重于舆情全流程梳理、任务下达及单位执行。界面风格采用政府指挥中心典型的专业、严谨风格。

## 🎨 视觉规范

### 1. 颜色系统
- **主色 (Primary)**: `#5c7cff` (调色盘中的深蓝色/紫色)
- **辅助色 (Secondary)**: `#ebf0ff` (浅紫色背景)
- **背景色 (Background)**:
  - 侧边栏/顶部栏: `#f8faff` (极浅灰蓝)
  - 内容区背景: `#f0f2f5`
  - 卡片背景: `#ffffff`
- **文字颜色**:
  - 正文: `rgba(0, 0, 0, 0.85)`
  - 次要: `rgba(0, 0, 0, 0.45)`

### 2. 布局结构
- **顶部导航 (Header)**: 高度 64px，固定。包含系统名称、功能按钮、搜索及用户信息。
- **侧边栏 (Sidebar)**: 宽度 110px，固定。仅显示图标+文字，垂直排列。
- **内容区 (Content)**: 弹性布局，内边距 16px。

## 🧩 功能模块

### 1. 顶部导航 (Header)
- **左侧**:
  - Logo/名称: “智控平台”
  - 按钮组: “手工上报”、“快捷指令”
- **右侧**:
  - 搜索框: 支持全网/关键词搜索
  - 操作图标: 返回导航页、背景切换、消息通知、退出登录
  - 用户信息: 欢迎语、修改密码、值班表、岗位切换

### 2. 侧边菜单 (Sidebar)
- **源头防控**: 核心看板（当前默认页）
- **监测预警**: 待开发占位
- **应急处置**: 待开发占位
- **复盘总结**: 待开发占位
- **工具箱**: 待开发占位

### 3. 源头防控页 (Dashboard)
- **统计卡片**: “数据概览”包含 7 个关键指标
- **节点卡片**: “敏感时间/事件节点”水平滑动列表
- **工作区**: 大面积空白区，提示“请创建管控任务!”

## 🛠 技术实现
- **框架**: React + Ant Design
- **状态管理**: useState (控制 `activePage`)
- **样式**: Vanilla CSS + Ant Design ConfigProvider
- **路径**: `/src/prototypes/gov_control_platform/`
