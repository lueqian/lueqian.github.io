# 设计演示沙盒 (Design Playground) 规格说明书

## 📋 业务与功能

### 1.1 核心目标
本原型旨在为开发和设计团队提供一个统一、精致、可高保真演示的“微设计”样板间。它能够：
1. **隔离修改风险**：不用直接在大型主项目中修改样式让客户确认，避免无谓的分支污染。
2. **像素级比对**：通过 Before/After 分屏拉杆组件，最直观地呈现实时修改的视觉提升。
3. **参数化体验**：让非设计人员/客户通过拖拽滑杆，直观感受圆角、阴影、间距对界面“呼吸感”的影响。
4. **易于扩展**：采用模块化注册机制，当需要展示新的局部重构时，极易新增子页面。

### 1.2 功能清单
- **左侧工作台导航**：支持首页及按“分类”组织的微调项目菜单，支持手机端侧边栏抽屉。
- **全局明暗主题切换**：支持一键在 Premium 明暗模式下比对样式表现。
- **效果预览视图**：支持带 Slider 控制器的 UI 实时渲染微调。
- **Before/After 视图**：支持滑块拖拽的覆盖对比。
- **设计说明视图**：结构化展示痛点、重构方案以及设计原则。
- **代码展示视图**：Before/After 关键 CSS/HTML 代码比对并支持一键复制。

### 1.3 交互要点
- **Before/After 分割条拖动**：按下中间 Handle 并左右移动鼠标/手指，拉杆应跟随移动，并通过修改右侧 After 容器的 `clip-path: inset(0 0 0 [POS]%)`，实现无形变、零延迟的分屏切割展示。
- **全局明暗切换**：点击 Sun/Moon 图标，在原型最外层容器切换 `.dark` 类，全站样式（包括卡片内部和预览区）应在 200ms 内平滑过渡。
- **滑块微调联动**：修改 Range Input 时，对应 state 变更，直观应用到预览卡片的 inline styles。

## 📊 内容规划

### 2.1 信息架构
```
Design Playground
├── 顶部 Header (面包屑导航 + 连接就绪指示灯 + 主题切换)
├── 左侧 Sidebar (导航分类 + 首页入口 + 版本号)
└── 右侧 Canvas 主画布
    ├── Tab 视图控制器 (预览 / 对比 / 说明 / 代码)
    └── 视图渲染区
        ├── 首页介绍 (功能总结 + 新增案例三部曲教程)
        ├── 软阴影案例 (Before 粗生硬投影 vs After 三层软投影，可调模糊/不透明/圆角/毛玻璃)
        └── 表单间距案例 (Before 拥挤无状态 vs After 呼吸感输入，可调行距/内边距/圆角/高光)
```

### 2.2 数据来源
- 本沙盒案例数据均为本地构造的静态 JSON/State，用于纯前端的高保真演示。
- 输入组件支持用户的即时文本输入交互。

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：分栏布局（左侧固定 256px 侧边栏，右侧自适应弹性内容区）。
- **头部高度**：64px (`h-16`)。
- **Tab 栏高度**：48px (`h-12`)。
- **响应式断点**：在宽度 < 768px 时，左侧侧边栏自动隐藏，顶部 Header 左侧显示汉堡菜单按钮以触发侧边栏抽屉（Drawer）。

## 🎨 视觉规范

### 4.1 设计规范来源
**设计规范来源**：内置 `interface-design` 和 `frontend-design` 的高级混合模式。

### 4.2 自定义设计要点
- **深色底色**：使用了极富深邃感的墨蓝黑 `#0f172a` (Slate 900) 以及深黑 `#090d16`，结合天蓝色高光提升科技质感。
- **卡片毛玻璃**：
  - 背景：`rgba(255, 255, 255, 0.7)` (明亮) / `rgba(15, 23, 42, 0.75)` (深色)。
  - 模糊：`backdrop-filter: blur(16px)`。

### 4.3 组件状态
- **菜单悬停态**：`bg-slate-50` (明亮) / `bg-slate-850` (深色)，带有微动效。
- **激活态**：左侧菜单激活为 `bg-sky-500` 白色文字，伴有阴影投影。
- **输入框聚焦态**：聚焦时边框色转为 `border-sky-500` 并伴有 `box-shadow: 0 0 0 4px rgba(14,165,233,0.1)` 柔和外发光。
