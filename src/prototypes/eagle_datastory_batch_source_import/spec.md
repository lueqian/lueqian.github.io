# Eagle DataStory - 信源批量导入与建库

## 业务与功能

### 核心目标

`eagle_datastory_batch_source_import` 是“数说蓝鹰”定向采集与重点源批量导入建库原型。在原有的搜索、全网专题、重点源、采集任务和额度明细闭环基础上，重点支撑**重点源信源批量导入与建库**业务流程：
- 支持基于 Excel/CSV 表格单列 URL 进行批量导入与毫秒级实体匹配；
- 形成“精准匹配 (1:1)”、“实体冲突左右并排选择 (1:N)”、“未命中链接自动补采”闭环；
- 支持实时配额校验、目录挂载绑定（现有目录/新建目录）以及下次登录异步补采结果通知；
- 在顶部常驻**【研发场景切换栏】(Scenario Switcher)**，一键切换并演示 5 个核心业务场景；
- 在右侧常驻折叠抽屉**【📖 研发交互与逻辑标注 (Dev Notes)】**，直观呈现 API 逻辑、参数校验与数据库持久化规范；
- 扩展**信源单日采集限额风控与定向截取功能**：
  - **Pre-occupation Model（并发任务日负荷预占模型）**：统计已有任务日预占 $E_p$，叠加待提交任务日增量 $N_p$；
  - **Implicit Risk Control（隐性风控原则）**：严禁对外透出具体限额数值（不暴露 1000 上限），超标时抛出硬阻断提示与 4 条调优建议；
  - **Top N 互动量数据截取策略**：专题/重点源支持“按互动量优先采集 Top N 帖文”，从源头削峰降载；
  - **小红书合并限额风控约束**：互动量与评论翻页单日合并上限 1,000 次/天（翻页单次按 1 次计算），超标时链接行高亮 `[小红书 · 待调减]`，提交按钮切换为禁用态。

### 5 大核心业务场景清单

1. **场景 1：入口触发与文件上传 (Entry & Upload State)**
   - **底图背景**：高保真复刻信源搜索主界面（含深蓝顶栏 `#0F1D38`、居中搜索框及筛选 Tag 标签组）。
   - **触发入口**：主搜索框右侧【搜索】按钮旁渲染幽灵线框按钮 `【批量导入检索】`，点击弹出 880px 宽度的居中遮罩 Modal。
   - **弹窗内呈现**：
     - 虚线拖拽上传区（Dropzone），提示“点击或拖拽 Excel 文件至此（.xlsx / .csv）”；
     - 限制说明：“单次上限 500 行，仅支持用户主页 URL 单列导入，自动过滤无效通用主域名”；
     - 提供“📄 下载标准 Excel 模板”文字链接；
     - 点击上传区可直接模拟载入 Mock Data 并展示 1.5 秒进度条动效，随后自动推进至场景 2。

2. **场景 2：理想链路 - 精准匹配与批量建库 (Happy Path: 1-to-1 Match)**
   - **三 Tab 导航**：`精准匹配 (28)` (激活)、`多实体冲突 (2)` (黄色预警小圆点)、`未匹配链接 (5)`。
   - **精准匹配列表**：表头提供 Checkbox 支持一键全选/取消全选，账号行卡片展示平台 Icon、头像、昵称、认证类型胶囊标签 (PGC/自媒体)、唯一 UID、粉丝数（如 1105W）、原始 URL。
   - **底部目录绑定栏**：
     - 单选 A：`加入现有目录`，下拉框可选“涉华博主 (余量: 342/500)”或“行业竞品 (余量: 410/500)”；
     - 单选 B：`新建目录`，输入框限制 20 字符以内，可见性单选 (`所有人可见` / `仅个人可见`)；
     - 实时配额校验：已选总账号数（精准匹配已选 + 冲突选定实体，初始共 30 个）超过目录剩余容量时，高亮报警并禁用提交按钮；
     - 点击【确认导入目录】触发全局 Toast：“成功将 30 个账号加入目录【涉华博主】”，弹窗关闭。

3. **场景 3：异常消歧 - 多实体冲突手动裁决与动态计数联动 (Conflict Resolution: 1-to-N Match)**
   - **Tab 2 激活**：展示说明文案与选定状态徽标：“系统已为以下 2 个冲突链接默认预选推荐实体（已计入底部已选）；选择实体‘+1’，选择暂不关注‘-1’”。
   - **左右并排候选实体卡片**：
     - 原始 URL 以代码块样式展示（如 `https://v.douyin.com/iJXXXXX/`）；
     - 左右并排罗列 2 个候选账号（候选 A 快手张三疯 1105W、候选 B 抖音张三发 987W）；
     - **默认预选机制**：解析完成后，每个冲突链接实体均**默认选中第一个候选用户（候选 A）**；
     - **互斥 Radio 单选与动态计数联动**：
       - 当用户选择选项 C `暂不关注此链接 (跳过此条)` 时：候选区域轻度置灰，该冲突项贡献的实体数由 1 降为 0，**底部提交按钮已选计数立即对应执行“-1”**；
       - 当用户从跳过状态重新选择某个具体候选实体（A 或 B）时：**底部提交按钮已选计数立即对应执行“+1”**；
       - 当用户在候选 A 与候选 B 之间切换时：总已选计数保持不变；
     - **防漏选阻断**：若存在未指定裁决的冲突项，触发红色震动边框与 Tooltip 提醒：“请为此冲突项指定唯一目标账号”。

4. **场景 4：兜底链路 - 未命中提取与异步补采 (Fallback & Auto-crawl)**
   - **Tab 3 激活**：灰底只读 TextArea 紧凑展示 5 个未命中的原始链接。
   - **一键复制**：右上角配置【一键复制全部未命中链接】按钮，点击弹出已复制 Toast。
   - **异步补采选择器**：默认勾选 `[√] 提交后台自动采集并在入库完成后自动加入选定目录`，明确提示后台将为链接下发爬虫任务，并在下次登录时弹窗通知。
   - **底部行动点联动**：提交按钮文案动态变为 `【确认导入 (已选 30 个) 并提交补采 (5 个)】`（已选数量响应精准匹配与冲突裁决结果实时动态更新）。

5. **场景 5：闭环通知 - 采集完成后下次登录提醒 (Next-login Notification Modal)**
   - 模拟用户重新登录系统主控制台的初始状态。
   - 居中弹出 520px 轻量级通知 Modal，配置浅绿/浅蓝顶饰与 CheckCircle 图标。
   - 标题：“信源自动补采完成通知”。
   - 罗列成功建档入库的 4 个账号胶囊信息（头像 + 昵称 + 平台 + 粉丝数），并挂载至目录【涉华博主】。
   - 提示“1 个链接因目标主页已注销未能抓取”。
   - 底部按钮：`【进入该重点源目录查看】`（一键跳转并高亮该重点源目录）、`【我知道了】`。

## 布局与结构规范

- **栅格标准**：12-column grid 响应式对齐。
- **表单与卡片**：浅色背景 `#F8FAFC`，卡片 `#FFFFFF` 配 1px 细边框 `#E2E8F0`，圆角 `8px`。
- **弹窗尺寸与防折行优化**：
  - `BatchSourceImportModal` 宽度扩展至 **1080px (max-w-[95vw])**，彻底消除中英文文本与操作按钮的拥挤挤压感；
  - 底部目录挂载栏、单选框、下拉框及操作按钮全面强化 `whitespace-nowrap` 与 `shrink-0`，杜绝任何换行；
  - 目录余量下拉选择器宽度从 192px 扩展至 240px，避免 `(余量: 342/500)` 被省略号截断；
  - 账号卡片原始 URL 宽度上限由 280px 扩展至 480px，整体视觉协调舒展。
- **顶栏中控双极化架构**：
  - 左侧核心业务流区块：组件水平 gap 固定在 `10px - 14px`，避免宽屏过度拉伸；
  - 右侧研发操作区块：工具间距 `8px`，一键呼出 Dev Notes。
- **纯净演示模式**：支持点击按钮或按键盘快捷键 `V` / `v` 自由切换，隐藏顶栏中控进入无干扰演示。
