# Eagle DataStory (Memecoin) 原型规格说明书

## 📋 业务与功能

### 1.1 核心目标
本原型系统是针对 **Memecoin（迷因币/模因币）** 的海外发现与监测研判专版。通过整合海外主流社交媒体（Twitter, Telegram, YouTube 等）、境外新闻等多个维度的数据，帮助用户快速发现并分析海外的 Memecoin 热点、意见领袖（KOL）、交易群体动向以及潜在舆情。

### 1.2 功能清单

本系统采用多页面切换架构，各子功能模块及其优先级如下：

- **搜索 (search) [P0]**：支持多维词句检索、支持特殊符号与逻辑运算。
- **海外发现 (overseas) [P0]**：本系统的核心焦点。支持针对海外站点（Twitter, Telegram 等）、各语种、国家地区的精准信息检索与趋势发现，提供翻译助手。
- **智能推荐 (recommend) [P1]**：基于智能算法挖掘并推荐海外的热门话题与关联内容。
- **全网专题 (topic) [P1]**：热点事件专题分析与态势追踪。
- **重点源管理 (source) [P1]**：对重点海外账号、特定频道等重点监测源的增删改查。
- **TG群管理 (tg_groups) [P1]**：Telegram 群组的布控、生命周期管理与跨群成员溯源研判。
- **采集任务 (collect) [P2]**：用于管理实时采集海外站点任务的下发与状态监控。
- **额度明细 (quota) [P2]**：查看数据采集额度消耗与明细。
- **工单管理 (ticket_admin) [P2]**：工单管理后台，用于解决需求反馈和采集线索的闭环跟进。

### 1.3 交互要点

- **全局导航切换**：点击侧边栏（Navigation）的菜单项 → 切换全局 `activePage` 状态并渲染对应页面，并在 Header 展示当前页面标题。
- **海外发现搜索**：在“海外发现”页面输入关键词并点击【搜索】 → 提交搜索请求，将关键词加入搜索历史，更新页面展示。
- **侧边栏折叠**：点击导航底部的折叠按钮 → 侧边栏宽度在 `240px` (展开) 与 `64px` (折叠) 之间平滑切换。
- **工单反馈抽屉**：点击顶部 Header 的【工单反馈】或消息图标 → 打开 1350px 宽 of 工单反馈抽屉。

## 📊 内容规划

### 2.1 信息架构

```
Eagle DataStory (Memecoin)
├── 全局布局
│   ├── Navigation (侧边导航栏，支持折叠)
│   └── Header (顶部状态栏，含工单抽屉入口)
└── 核心子页面
    ├── 搜索页 (Search.tsx)
    ├── 智能推荐页 (SmartRecommend.tsx)
    ├── 全网专题页 (Topics.tsx)
    ├── 海外发现页 (OverseasTopics.tsx) [核心关注页]
    │   ├── 搜索区 (输入框 + 翻译助手)
    │   ├── 过滤面板 (站点、语种、地区、匹配方式、类型)
    │   └── 搜索历史
    ├── 重点源管理页 (Sources.tsx)
    ├── TG群管理页 (TGGroups.tsx)
    ├── 采集任务页 (CollectTask.tsx)
    └── 额度明细页 (QuotaFlow.tsx)
```

### 2.2 数据来源

- **数据类型**：海外舆情与社交媒体发文数据、TG群组状态、工单明细。
- **数据源**：生成示例数据（Mock Data），后续可对接具体的数据接口。
- **关键字段**：
  - `keyword`: 检索关键词
  - `site`: 目标站点 (Twitter, Telegram, YouTube 等)
  - `language`: 语言类型 (英语, 中文, 日语等)
  - `country`: 目标国家地区 (美国, 俄罗斯, 英国等)

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：左右两栏结构。左侧为固定/折叠导航栏，右侧为内容区。内容区顶部为 Header 栏，下方为具体页面内容。
- **容器宽度**：响应式流式布局。
- **关键尺寸**：
  - 侧边栏展开：`240px`，折叠：`64px`。
  - Header 高度：`64px`。
  - 内容区左右留白：`24px`，上下留白：`24px`。

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置基础型界面设计规范 `interface-design`，同时遵循深色主题主色调设计。

### 4.2 自定义设计要点

- **主题背景**：全局采用深色/暗色调背景，提升科技感与专业度。
- **聊天/研判区域**：在 TG 群组研判的双栏抽屉中，聊天列表区域采用浅色背景（Light Gray Bubble），与全局深色大背景形成对比，增强阅读专注度与文本对比度。

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onMenuSelect` | `string` | 点击侧边菜单项时触发 | 返回选中的菜单 key |
| `onLogout` | `void` | 点击退出登录时触发 | 触发退出登录流程 |
| `onSwitchAccount` | `void` | 点击切换账号时触发 | 触发账号切换 |
| `onBackToNav` | `void` | 点击返回导航页时触发 | 导航回上一级平台 |

### 5.2 动作列表（actionList）

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `setPage` | `string` | 页面 key (search/workbench/topic/source/collect/quota/overseas) | 切换到指定页面 |
| `setSidebarCollapsed` | `string` | "true" / "false" | 设置侧边栏的折叠/展开状态 |

### 5.3 变量列表（varList）

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `selected_menu` | `string` | `"search"` | 当前选中的菜单项 key |
| `sidebar_collapsed` | `boolean` | `false` | 侧边栏是否折叠 |
