## 为什么必须指定路径？

Axhub Make 通过扫描 `src/prototypes/` 下的子目录来识别原型。**唯一识别条件是子目录中存在 `index.tsx` 文件**。

如果 AI 在根目录或其他位置生成了 HTML 文件，系统无法识别它为一个原型页面，在 `localhost:51720` 中也不会显示。

| ✅ 正确做法 | ❌ 错误做法 |
|------------|------------|
| `src/prototypes/my-feature/index.tsx` | 根目录 `index.html` |
| `src/prototypes/my-feature/style.css` | `src/my-feature.html` |
| `src/prototypes/my-feature/spec.md` | 任何不在 `src/prototypes/` 下的文件 |
