# 蓝鹰一体化系统 - 人员库操作手册

本手册旨在指导系统管理员和值班警务人员，说明蓝鹰一体化系统中**人员库**的功能定位、数据结构、展示方式，以及如何通过业务指令流转、社群登记、画像同步等方式将人员信息登记入库。

---

## 一、 人员库功能定位与概述

**人员库**是蓝鹰一体化系统的核心基础模块之一。它作为**涉事网民身份与社交账号的聚合档案库**，旨在打破线上舆情账号与线下网民真实身份之间的壁垒，构建全量关联图谱。

为符合内网合规及信息安全要求，系统对人员库进行了以下优化：
1. **去风险化描述**：彻底去除了所有关于“人员风险等级”的字段描述和彩色标识，回归纯客观底盘数据。
2. **防泄密暗水印**：全页面覆盖低饱和度的动态暗水印图层（水印文字：`LAN YING INTRANET`），保障内网信息安全。
3. **数据融合防重**：支持“舆情指令来源”与“涉稳登记来源”的数据排重与防重碰撞画像融合。

---

## 二、 人员库包含的数据字段

人员档案由基础身份、管控状态、社交账号、关联事件及帖文脉络等多维数据共同构成：

### 1. 基础身份信息
* **姓名**：网民/涉事人员姓名（在前台界面已进行脱敏展示，如：张某民）。
* **性别**、**年龄**、**民族**、**出生日期**。
* **脱敏身份证号**：用于跨系统比对与防重识别（如：`3208************12`）。
* **脱敏手机号**：用于通讯关联（如：`178****5678`）。
* **居住地 / 户籍地**：标记涉事人员的常住及原籍属地，外层列表及卡片视图均直观展示“归属地”与“户籍地”字段。
* **责任属地**：管辖该人员的警务责任单位（如：清江浦区、淮安区等）。
* **备注说明**：人员建档的背景说明（如：“由舆情指令来源快速建档登记”）。

### 2. 标签与管控状态
* **管控状态**：展示该人员当前的管控处置阶段，包括：
  * `重点监控` (monitored)
  * `已劝导 / 属地已接话劝导中` (convinced)
  * `已离开 / 已被现场民警劝离` (left)
  * `常态` (normal)
* **胶囊标签**：直观展示人员在事件中的属性（如：`重点线下组织者`、`敏感传播源`、`现场聚集跟随人员`、`双源头融合`等）。

### 3. 关联社交账号（大V/自媒体特征）
人员库支持绑定多个主流社交媒体平台的账号：
* **关联平台**：微博（Weibo）、微信（Wechat）、抖音（Douyin）等。
* **账号昵称**及**社交ID (UID)**。
* **粉丝数**及**传播度指标**。
* **网络属性分类**：区分网民类型为 `自媒体`、`大V` 或 `普通网民`。

### 4. 关联事件与客观帖文脉络
* **关联事件总数**：该人员被卷入的线下聚集或线上舆情事件的累计次数。
* **客观帖文脉络流**：完全由客观的原始发帖源数据与内网穿透取证构成，**取消了一切 AI 润色或主观研判**，保障取证材料的法律真实性。

## 三、 人员信息的展示、检索与筛选

人员库界面为值班人员提供了高效的多维检索与可视化的档案展示：

### 1. 顶部检索与筛选
* **多维模糊检索**：支持在检索框内直接输入 `姓名`、`身份证号`、`手机号` 或 `社交账号ID` 进行实时模糊匹配。
* **属性分类下拉多选**：左侧原有的“人员属性多级分类”菜单已收纳至顶部，提供多选 TreeSelect 过滤（如：外卖员群体、出租车群体、某小区业主、房产维权、退役军人等）。
* **人员来源过滤**：集成“全部”、“舆情指令”、“涉稳登记”三大人员来源过滤器。

### 2. 人员画像穿透展示
在列表或卡片视图中，点击任意网民姓名，均可拉起“人员详情弹窗”：
* **结构化布局**：包含“人员信息”、“关联账号”与“关联事件”三大核心板块。
* **客观脉络穿透**：展示该网民关联的客观发帖轨迹。

## 四、 如何登记人员信息入人员库

为了防止前台违规手工录入，系统**隐藏了“登记人员”和“标签管理”按钮入口**，转而采用**基于业务流程的“同步与流转登记”机制**。人员信息主要通过以下三种途径录入：

### 途径 1：稳情库涉稳人员“一键同步”
在**源头防控（稳情库）**模块的“涉稳人员活跃度视图”中：
1. 浏览涉稳重点人员列表（支持通过人名、户籍地模糊检索）。
2. 点击任意未录入人员档案右侧的“**同步状态**”标签（显示为“`未录入人员库（点击同步）`”）。
3. 触发系统同步，将该涉稳网民特征及其画像一键穿透写入人员库。

### 途径 2：涉稳群组登记“解析自动同步”
在对线下两群（微信/QQ群等涉稳私域群组）进行登记时：
1. 在稳情库模块点击“**登记涉稳群组**”，弹出双通道登记弹窗。
2. 将外部群反馈的文本或聊天记录长文本直接粘贴到左侧解析区域。
3. 点击“**一键解析并结构化**”，系统自动分析并提取出群基本信息及群成员明细列表。
4. 确认信息无误后点击“**确认提交**”，该群组信息将入库，且关联的群成员名单将**自动同步汇总、去重并登记入人员库**。

### 途径 3：处置指令流转与“防重碰撞融合”
在警舆同处和应急处置流程中，下达指令后会伴随网民身份的防重碰撞录入：
1. **指令下达与回传**：下达补拍或现场核查指令后，属地反馈或内网侦听捕获涉事网民身份及社交平台账号。
2. **防重碰撞拦截**：在进行人员建档提交时，系统后台会对身份证号、手机号、社交账号 ID 等唯一标识进行碰撞检测：
   * **未碰撞**：正常新建人员档案，并标明来源为 `舆情指令来源 (opinion)`。
   * **已碰撞**：系统拦截提交，并弹出“**防重碰撞合并画像**”弹窗，展示待登记信息与库中已有档案的比对结果。
3. **画像合并融合**：值班员确认执行合并后，系统会将新录入的社交账号和事件标签追加合并至已有档案，并将该人员的来源形态升级为“**双源头融合 (both)**”。
