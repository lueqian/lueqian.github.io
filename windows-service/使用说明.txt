===================================================
             蓝鹰一体化系统 - Windows 部署与使用说明
===================================================

本文件夹 (windows-service) 包含了在 Windows 11 系统下一键部署与启动 Axhub 原型服务的脚本。

---------------------------------------------------
一、 目录结构说明
---------------------------------------------------
把当前项目全部文件拷贝到 Windows 工作电脑后，本工具箱包含：
  ├─ setup_env.bat      <-- 环境一键安装脚本（初次部署运行）
  ├─ start_service.bat  <-- 服务一键启动脚本（平时运行）
  └─ 使用说明.txt       <-- 本教程文件

---------------------------------------------------
二、 初次部署环境 (只需操作一次)
---------------------------------------------------
在一台新的 Windows 11 工作电脑上，请按顺序执行以下操作：

1. 双击运行 `setup_env.bat`；
2. 如果系统弹出提示要求“管理员权限”，请点击“是”以允许运行；
3. 脚本会自动使用 Win11 自带的包管理器检测并安装：
   - Node.js LTS
   - Python 3
4. 提示安装成功后，窗口会告知你需要更新环境变量，并提示按任意键退出；
5. 按任意键退出窗口后，【再次双击运行】 `setup_env.bat`；
6. 此时脚本会识别到刚才安装的环境，自动安装 pnpm 并自动开始执行 `pnpm install` 拉取本项目的 node_modules 依赖包；
7. 依赖安装完成后，窗口会提示“所有依赖环境安装成功！”，此时即可关闭该窗口。

---------------------------------------------------
三、 日常启动服务 (每次启动原型时运行)
---------------------------------------------------
在环境成功配置后，每次需要向团队公开原型时：

1. 双击运行 `start_service.bat`；
2. 窗口启动后，会以如下列表显示本机的局域网 IP 地址：
   ===================================================
   [局域网共享信息] 
   本机正在使用的局域网 IP 地址如下:
     - http://192.168.1.105:51720
   ===================================================
3. 服务会自动跑起来，保持此命令行窗口【不要关闭】；
4. 团队成员只需要连接到同一个局域网或 Wi-Fi下，在浏览器里输入上面提示的局域网 IP 链接（例如 http://192.168.1.105:51720 ），就能直接查看并交互你的 AxHub 原型。

---------------------------------------------------
四、 常见问题排除
---------------------------------------------------
1. 局域网内其他电脑无法访问？
   答：通常是因为 Windows 防火墙拦截了端口。可以尝试：
       - 打开“控制面板” -> “系统和安全” -> “Windows Defender 防火墙”；
       - 选择“允许应用或功能通过 Windows Defender 防火墙”；
       - 点击“更改设置”，确保“Node.js JavaScript Runtime”或对应端口（51720）在公用和专用网络下都是勾选允许的。
       - 或者临时关闭防火墙进行测试。

2. 电脑重启或断电后服务断开？
   答：直接重新双击运行 `start_service.bat` 即可恢复服务，无需重新安装环境。
